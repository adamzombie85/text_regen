41研究室 文本分析助手 - 使用說明校對文件
==================================================

--------------------------------------------------
【中語介面版本 - Mandarin Version】
--------------------------------------------------

[步驟 1]
標題：1. 貼上原文
描述：請在首頁的輸入框中，貼上您準備做為教材或是需要進行難度分析的原始文章。系統目前支援純文字格式，您可以貼上整篇短文或新聞，完成後點擊「開始文本分析」即可進入下一步。

[步驟 2]
標題：2. 文本分析
描述：系統會自動為您的文章進行字頻統計，並對照「中語 5021 常用字表」及「台語 700 常用字表」進行排名。您可以透過數據總表與區間分佈表，快速評估該文本對於學習者的難易度。表格的表頭也支援點擊排序，方便您找出最艱澀的字彙！

[步驟 3]
標題：3. AI 產出
描述：根據前一步的分析結果，您可以設定希望 AI 改寫的「目標長度百分比」與「常用字排名上限」。系統將會調用專屬的 AI 語料庫（中語腦 / 台語腦），為您產出符合特定難度且語氣道地的改寫文章，大幅節省備課時間。

[步驟 4]
標題：4. 如何取得 API 金鑰
描述：
1. 前往 Google AI Studio (https://aistudio.google.com/) 並登入。
2. 點擊左側 "Get API key"。
3. 點擊 "Create API key"。
4. 複製金鑰並貼回到本網頁輸入框即可。

--------------------------------------------------
【台語介面版本 - Taiwanese Version】
--------------------------------------------------

[步驟 1]
標題：1. 貼原文
描述：請佇首頁的輸入格仔內，共你準備欲提來做教材，抑是需要分析難度的原始文章貼起去。系統目前支援純文字，你會使共規篇短文抑是新聞貼起去，貼好勢了後，點擊「開始分析文本」就會當落去後一步。

[步驟 2]
標題：2. 分析報告
描述：系統會自動替你的文章做字頻統計，閣會對照「中語 5021 捷用字表」佮「台語 700 捷用字表」落去排順序。你會使透過數據總表佮區間分佈表，快速評估這篇文章對學習者敢會傷困難。表格的順序嘛會當透過點擊頂懸的表頭來重排喔！

[步驟 3]
標題：3. AI 改寫
描述：照頂一步的分析結果，你會使設定你希望 AI 改寫的「目標文本長度百分比」佮「捷用字排名上限」。系統會去調用專屬的 AI 語料庫（中語腦 / 台語腦），替你寫出一篇難度適合而且有在地氣口的文章，替你省落濟濟備課的時間。

[步驟 4]
標題：4. 去佗位攑金鎖匙 (API Key)
描述：
1. 去 Google AI Studio (https://aistudio.google.com/) 登入你的口座。
2. 點擊倒手爿的 "Get API key"。
3. 點擊 "Create API key"。
4. 共金鎖匙khóo-pih起來，提轉來遮貼起去就會使矣。
